# RAG-chat 🧠📄

**RAG-chat** is a Retrieval-Augmented Generation (RAG) based chatbot that allows users to upload various file types (PDF, DOCX, HTML, etc.) and get intelligent summaries or answers to questions based on the uploaded content. It combines the power of LLMs with vector search for accurate, context-aware responses.

---

## 🔍 Features

- 📄 Upload support for **PDF**, **DOCX**, **HTML**, and more  
- 💬 Chat interface powered by **LLMs (like GPT)**  
- 📚 Uses **vector database** for retrieving relevant chunks  
- ✨ Summarization and Q&A based on your own files  
- 🧠 Built using **RAG (Retrieval-Augmented Generation)** architecture

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit / React (based on your setup)  
- **Backend:** Python, LangChain  
- **LLM:** OpenAI GPT / any LLM of your choice  
- **Vector DB:** FAISS / Chroma  
- **Parsing:** PyMuPDF, python-docx, BeautifulSoup
